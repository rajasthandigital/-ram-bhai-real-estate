# Ram Bhai Real Estate Agent — GitHub Pages App

A responsive web app built from the supplied UI reference. It includes:

- Welcome screen
- Mobile/Gmail login UI
- Property search and property type selection
- Budget range selection
- Availability result
- Meet-agent request form
- Admin login
- Admin dashboard
- Add property form
- Meeting requests table
- LocalStorage persistence for demo data
- Responsive desktop/mobile layout

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `ram-bhai-real-estate`.
2. Upload `index.html`, `styles.css`, `app.js`, and `reference-design.jpg`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The app is a front-end demo; real authentication, database storage, WhatsApp/SMS, and a production admin backend would need to be connected separately.
