# Real Estate Agent Ram Bhai — Full Screen App

This version is configured as a true fullscreen PWA. The old desktop “phone/page frame” has been removed.

## Install
- Android Chrome: open the GitHub Pages URL and choose **Install App** / browser install prompt.
- iPhone Safari: Share → Add to Home Screen.
- After installation, launch it from the home-screen icon. It will open in fullscreen app mode.

## Important
The browser will still show the normal webpage UI while you are viewing the URL directly in a browser tab. Fullscreen mode applies when the PWA is launched as an installed app.
